## Uploading to cloud

- [ ] Name the installer something like `game.dat` (do NOT upload exe files)
- [ ] Upload renamed file on anonymous cloud services like
[catbox.moe](https://catbox.moe/) while using VPN or Tor

## Installing on target device

> [!CAUTION]
> Do NOT use command line tools like curl because most
> console applications stores command history

- [ ] Download on the target device using incognito mode on browser
- [ ] Change the extension back to `.exe` and run
